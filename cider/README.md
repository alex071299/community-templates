# Cider

Applies Noctalia's colors to [Cider](https://cider.sh/) using a ThemeKit stylesheet.

The template installs `noctalia.scss` and `theme.yml` into Cider's `themes/noctalia` directory. Native and Flatpak installations are supported.

In Cider, open the theme settings, select **Noctalia** and enable **Noctalia Dynamic**. For automatic updates when the Noctalia palette changes, enable Cider's theme file watcher in the extensions settings.
